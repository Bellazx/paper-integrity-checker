# 初审数量一致性检查

2026-10-23：针对六篇漏检案例增加可复算的正文/源表检查，不读取 DOI 白名单、既有复核结论或归档报告。

`core.pipeline.analyze_paper` 在初审评分之前调用 `modules.quantitative_consistency.check_quantitative_consistency`。普通批量初审和 API 调用的 `main.py` 共用该路径。新发现写入 `data_anomalies`；读取/覆盖问题写入 `analysis_warnings`，不能作为论文风险证据。

| 检查 | 前提与边界 |
| --- | --- |
| NaCl分子数量与质量分数 | 同段明确给出每份溶液的水分子、Na+、Cl−数量及wt%；按摩尔质量计算，不把mol%当wt% |
| 三轴弹性能公式化简 | 完整识别上游三主应力公式及下游表达式，按σ2=σ3化简；仅报告印刷公式差异，不推断计算程序有误 |
| 模糊评价矩阵与加权得分 | 从PDF坐标读取矩阵和最终权重；维度匹配、权重和为1才计算，舍入容差0.003；无法识别的布局不作判定 |
| 同名浓度量的%／‰ | 同名图表量、正文‰范围、图轴附近未作十倍换算的多个数值共同支持；明确单位换算说明时跳过 |
| 声速区间概括与实验表 | 识别甲烷/THF的Vp、Vs列和明确的区间比较断言，逐行核对，允许1%的舍入/读数容差 |
| 蛋白计数与随文源表 | 正文必须直接关联具体表号；流式完整读取MaxQuant表，按Intensity>0及三个排除标志计数；至少两张表同口径复现成功，才报告其他表的计数差异，要求解释批次/筛选/分组 |

这些规则检出的是可定位、需解释或更正的问题，不等同于确认造假，也不保证覆盖所有公式、图点或实验设计问题。

## TXT/TSV读取和资源边界

直接上传和ZIP/RAR中的TXT/TSV表进入源数据读取。`doi.txt`与爬虫清单不作为实验数据。编码、分隔符和列名不能可靠识别时记录覆盖告警。告警同时穿过普通和隔离子进程路径。

通用数列扫描最多读取文本表前10000行、前200列，超过范围必须记录部分覆盖。蛋白计数检查独立流式读取所引用源表的全部行，不使用通用扫描的样本。任何部分覆盖均不能解释为整份材料已核验通过。

关键复算发现优先进入报告提示词，避免被大量弱统计告警挤掉。报告说明生成失败时，数据为唯一风险维度且存在完整数量证据的情形使用确定性证据说明；有其他未解释风险维度则报告生成失败，不把已检出的数量问题改成0分。

## 验证

`tests/test_initial_quantitative_consistency.py` 包含正确数值、已换算单位、不匹配上下文、正确公式、舍入容差、阳性对照不足、TXT编码/容量/失败传播、共享CLI流程及报告说明回退测试。

该文件末尾的六篇本地材料集成测试直接读取原始输入，缺少材料时跳过。测试不写数据库，不重新生成现有报告。六篇各检出一项：盐浓度、公式多项、加权评分、浓度单位、声速区间、蛋白计数。复杂图点数字化和动物编号对应关系仍由后续复核处理。
