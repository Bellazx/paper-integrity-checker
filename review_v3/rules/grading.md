# 定级规则（实质问题 vs 规范问题）

问题是否成立是一回事，定为“实质问题（substantive）”还是“规范问题（minor）”是另一回事。只有实质问题支持“有风险”。

## 判为实质问题（任一成立）
1. **数据真实性**：不同实验、样品、条件或时间点的测量值逐值复用或成块复制；同一图像/凝胶/显微图被用于不同实验或被拼接；测量值出现非自然规律（小数尾串继承、固定比例、CV=0、末位填充等）且无法由列语义解释。
2. **核心结果不可能成立**：论文报告的关键结果（摘要、结论、主图主表的核心比较）与论文自身数据或公式严重矛盾，例如差 2 倍以上、比较方向反转、样本量在数学上不可能、统计量不可能由所报数据得到，且无法用转录笔误唯一解释。
3. **系统性错配**：成行/成块互换、样品标签或工况互换，使关键结果归属到错误条件，并进入了结论。
4. **多处独立的实质矛盾**集中在核心结果上，形成模式，即使单处幅度中等。

## 判为规范问题（以下情形不支持“有风险”，但要写清楚并给出更正建议）
1. **可唯一反解的孤立笔误**：单个数值、置信区间界、子组计数、百分比、单位、正负号、小数点位、图例、面板字母、图号、表头错误，可由论文自身其他数据（合计、相邻表、正文、另一图）唯一还原，且还原后不改变任何结论。
2. **只在补充表、对比表或附表里**、没有传播到摘要/正文结论/主图的错误。
3. **报告口径问题**：统计口径（SD/SE、CI 方法、归一化基准、自由度约定）未说明或不一致，但没有证据表明数据被改变；可复现性说明缺失（随机种子、重复次数未写）。
4. **表述问题**：正文转述图表时方向、对象或工况写反，但图表本身自洽，结论不依赖这句转述；摘要/结论措辞过宽。
5. **著录问题**：参考文献编号、作者、页码、刊名缩写、重复著录、悬空引用。
6. **读图精度内的差异**，或差异可由统一的换算/归一化机制完整解释。

## 判定步骤
1. 真值能否由论文自身其他数据唯一确定？能 → 倾向规范问题。
2. 改正后是否改变任何结论、关键比较或摘要/正文中的数值？不改变 → 规范问题；改变 → 实质问题。
3. 是孤立一处，还是同类问题在核心结果中反复出现？反复出现 → 考虑实质问题。
4. 问题指向数据本身的真实性（复用、非自然生成），还是指向报告与转录？前者 → 实质问题。

拿不准时，按事实写清楚，并在 why 中说明上述四步各自的结论。
