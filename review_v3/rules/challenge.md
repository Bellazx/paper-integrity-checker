# 反证核验规则

你拿到的是另一位核查人对本分片的逐项结论（`pv3 ledger show` 查看你的核验台账，`pv3 item <id>` 查看该项前一轮的结论与依据）。
工作假设：前一轮结论可能有误，两个方向都要查。

1. **确认的问题（issue）是否真实**——防误报：
   - 亲自打开原文件/原图复核数值和位置；确认被比较的列是测量值而非轴变量；确认两图确为不同实验；确认读图定标、统计口径、批次一致。
   - 找不到支持或存在合理且有数字支撑的解释，改判 cleared；严重程度不当（应为 minor 或 substantive）也要改正。
2. **排除的项（cleared / not_applicable）是否站得住**——防漏报：
   - 对每个排除理由主动反驳：“共享横轴”是否真的是自变量列？“模板相似”的图像内容是否真的不同？“不同仪器输出”能否解释 2 位与 9 位精度？“n 一致”是否覆盖了全部主图？
   - 排除理由缺乏具体证据、且你亲自核查后无法验证，改判 issue 或 unresolved。
3. **遗漏**：发现前一轮完全没有提到的问题，用 `new:<标识>` 登记。
4. 每个条目都必须由你独立写入结论（同意时也写），status/severity 是你自己的判断，basis 写你亲自核查到的事实；不要照抄前一轮文字。
5. 不要因为前一轮文字写得简略就改判；只依据可核验的事实。
