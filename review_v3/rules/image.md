# 图像维度规则

- 对每组图像相似/拼接告警（`pv3 alerts image`）都要查看标注图或原图（`pv3 view <annotation>`），必要时对照原文页面（`pv3 render`）。
- 支持实质问题的情形：
  - 不同实验、不同样品或不同条件声称下的同一照片、同一凝胶/印迹、同一显微图（含旋转、翻转、裁剪、缩放、变色后的局部）。
  - 跨页真实图像内容重复（排除空白页、小缩略图和装饰元素）。
  - 拼接处背景灰度、曝光、分辨率或压缩质量明显不连续。
- 常见假阳性（视觉确认后才可排除，并写明依据）：
  - PDF 原图与正文嵌入版重复、投稿原始图片与排版页面重复、同一图的两种编码。
  - 坐标轴/图例/仪器信息条等版式模板，ROC/流程图等标准结构，同一 UMAP/tSNE 嵌入的不同着色，化学结构式，标准脑模板，有限元网格，微小缩略图。
  - 准周期纹理（晶格、纳米孔）易产生大量特征点匹配，需用位移一致性或子块相关判断。
  - 生信流水线图像相似时，确认轴标签、样本、点位或曲线含义是否不同；实际数据内容相同不能排除。
- “逐页浏览”项：渲染各主图页面（中等分辨率）快速浏览，只对可疑面板放大核查；未发现异常时写明浏览了哪些页和图号。
- 确认问题需给出两处的页码、图号与面板，附两处的局部截图（同一条 evidence 中可放多张）。
