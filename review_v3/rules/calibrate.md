# 定级复核规则

本台账列出本论文全部已确认的问题（含两轮核查与仲裁后的结论）。你的任务只是按定级规则逐条复核严重程度，并检查问题本身是否站得住。

- 对每条问题：先读 `pv3 item <id>` 中的位置、发现与依据；必要时打开原文件或渲染原图核实关键数值（只核实，不重新展开全文调查）。
- 按定级规则的判定步骤，写入结论：
  - 问题成立且为实质问题：status=issue，severity=substantive；
  - 问题成立但属规范问题：status=issue，severity=minor；
  - 核实后问题不成立：status=cleared，basis 写明原因。
- 保留原有的 location、issue_type、finding、basis 文字（可修正不准确处）；why 中写明定级理由（落在主要结果还是次要信息、是否影响结论或推荐、孤立还是反复出现、是否涉及数据真实性）。
- 主要结果（主结果表/主图的性能数值、平均值、提升幅度、推荐设置、正文核心数值）之间的矛盾，一处即为实质问题；不要因为“可能是转录笔误”就降级。
- 次要信息、叙述、口径说明和著录问题保持规范问题；但实验结果中出现 ≥3 处独立的数值矛盾时，把其中代表性的一处定为实质问题并说明模式。
