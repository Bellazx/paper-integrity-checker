# 定级复核规则

本台账列出本论文全部已确认的问题（含两轮核查与仲裁后的结论）。你的任务只是按定级规则逐条复核严重程度，并检查问题本身是否站得住。

- 对每条问题：先读 `pv3 item <id>` 中的位置、发现与依据；必要时打开原文件或渲染原图核实关键数值（只核实，不重新展开全文调查）。
- 按定级规则的判定步骤，写入结论：
  - 问题成立且为实质问题：status=issue，severity=substantive；
  - 问题成立但属规范问题：status=issue，severity=minor；
  - 核实后问题不成立：status=cleared，basis 写明原因。
- 保留原有的 location、issue_type、finding、basis 文字（可修正不准确处）；why 中写明定级理由（落在主要结果还是次要信息、是否影响结论或推荐、孤立还是反复出现、是否涉及数据真实性）。
- 先判断矛盾发生在哪里：主要结果的数据载体之间（表、图、补充表、源数据彼此不能同时成立），一处即为实质问题，不要因为“可能是转录笔误”就降级；例外是孤立单格不闭合、偏差远小于论文主张的效应且不改变任何比较或结论（定级规则规范问题第 8 条）。只是正文转述与自洽的数据载体不符、结论方向不变，定为规范问题。
- 论文的核心主张或核心比较（“显著改善”“几乎消失”“不受影响”“X 优于 Y”等）被本文自身图表否定的，定为实质问题，不要当作“表述过宽”降级。
- 对比表中引自其他文献的基线数值、图表离散度与表内 SD 的口径差异、公式量纲/记法问题，按定级规则规范问题第 1、9、10 条处理。
- 次要信息、叙述、正文转述、口径说明和著录问题保持规范问题；但实验结果中出现 ≥3 处独立的数据载体矛盾（表/图/源数据互斥，不含正文转述）时，把其中代表性的一处定为实质问题并说明模式。
