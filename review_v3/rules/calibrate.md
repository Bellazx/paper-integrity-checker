# 定级规则（按类别）

本台账列出本论文全部已确认的问题。你的任务是给每条问题选定一个类别；定级（实质问题/规范问题）由类别自动决定，你不需要也不能另行判断轻重。

## 做法
- 对每条问题，先读 `pv3 item <id>` 中的位置、发现与依据（字段 first）。基于这些记录分类；只有记录不足以判断类别时，才打开原文核对一个关键数值，不要重新展开调查。
- 先处理当前为实质问题的条目，再处理其余条目。
- 写入：问题成立 → status=issue，填 category（类别代码）与 why（为什么属于这一类：指出是哪两处数据互斥、哪句主张被哪张图表否定，或为什么只是孤立单格/转述/口径问题）；保留原有 location、issue_type、finding、basis（可修正不准确处）。核实后问题不成立 → status=cleared，basis 写明原因。
- 一条问题同时符合多个类别时，选最能代表它的那个；拿不准是 S 类还是 M 类时，逐条对照下表的“适用情形”，所有条件都满足才选 S 类。

## 判 S 类之前必须确认
- 两处数值是同一个量、同一条件、同一统计量、同一汇总范围：仿真与实测、双站与单站、单频与扫频、全程与绘出的部分采样点、含与不含初始收敛段，都不是同一个量。不能确认相同的，归 M4 或 M3。
- 表内 SD 与箱线图/误差棒比较前，先用 n 检验：n 个点的样本 SD 不可能超过极差 × √(n/(2(n−1)))（n=5 时约 0.56 倍）。超出只说明表里的 SD 不是图中这组数据的统计量（来自别的数据或别的口径），归 M4；不能据此判 S5“统计量不可能成立”，也不能判 S2。
- 矛盾数值是论文印出的，而不是复核人员推算或换口径得到的（后者归 M9）。用论文公式反推出的中间量（如由式(1)(2)反解出的最大/最小强度）与印出值不符，归 M3。
- 唯一的例外：论文写明了检测阈值或读取规则（如“以 12.1 dB 为可靠检测门限，从图中读取 MDV”），把同一规则用于论文自己的结果图，读数与“某现象被消除、不受影响、改善到某值”这类明确主张相反，按 S3。这只适用于读论文自己的图，不适用于用公式推算派生量。
- 问题涉及核心比较或主要结论。对子组件、单个示例的附带解读，与自洽的图表不符而结论方向不变，归 M2；主张只在扫描端点或有物理解释的边界不成立、主要区间成立，或两者持平，归 M8。
- 时序图与汇总值比较，要逐时刻或按均值/中位数比较，不能只用单点峰值；各曲线共同的初始值或收敛段不能当作某一方法的峰值。
- 定性检测图要判“漏检/误检”，先把真值面板的每个目标逐一对到被比较的面板。
- 不用三维透视曲面读取幅度、周期作为实质证据。
- 同一个事实已在其他条目归为 M 类时，汇总条目（如核心主张、统计复算）没有新的独立证据，不得用同一证据另立 S 类。
- 条目的影响说明写了“按规范问题处理”“不支持实质问题”时，类别不能是 S 类（代码会按规范问题处理）。

## 容易混淆的情形
- 主结果表里只有一个格不闭合、偏差不改变任何比较或结论 → M1，不是 S2。
- 同一个量在两张图/表中数值不同，并因此改变了方法排序或推荐 → S2。
- 结论或正文写“A 优于 B”“略有下降”“几乎消失”，而本文图表数值显示相反或无差异 → S3；只是措辞夸大、数值方向一致 → M8。
- 复核人员按另一种口径重算后得出“主张不成立” → M9，不是 S3。
- 公式写错、推导链不闭合、量纲混用，即使报告结果按该公式算出 → M3；只有核心方法公式会让方法起相反作用、文字未写明正确方向且无其他保障 → S6。描述性指标的预处理公式与同段文字方向相反 → M3。
- 输入参数表与正文派生量的标签错位、不影响任何比较 → M2 或 M10，不是 S4。
- 方法章节的通用符号或带省略号的示意图（如 Channel 1…Channel N）与仿真/实验给出的具体取值（如 N=2）不构成互斥；仿真输入参数写得不清楚 → M4 或 M6。只有能证明印出的结果数值因此与另一处互斥或被直接否定，才考虑 S 类。用“若参数为 X 则方法不能成立”推理时，必须先按论文自己写明的方法约束核对。
- 本文方法内部的参数或变体比较（如两种网格间距、两个支路），只在结果讨论中出现、没有写进摘要、贡献或结论、也不决定推荐设置，即使附有机理解释，与图表方向相反也归 M2；写进摘要、贡献或结论，或用来推荐某一设置时，按 S3。
- 判 S6 前检查：在交替或分解求解的算法中，被罚项约束的同一个量是否在另一个子问题中作为硬约束、并约束最终输出；邻近文字是否已用 penalty、minimize 等词写明方向。任一项成立 → M3。
- 正文写“在所有/各个数据集或设置上最佳”，而表中该范围内有一格基线更好（包括表格自己把最佳标给了别的方法）→ S3，不因差值小降级。
- 图中散点数少于 n → M5；用图中可见的点回算相关系数、回归式、比例或准确率而与报告值不同，在可见点少于 n 时仍是 M5（缺失或重叠的点本身就会改变回算结果），不是 S2。图中误差棒与表内 SD 不一致而口径未确认 → M4。
