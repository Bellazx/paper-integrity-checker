# 分歧仲裁规则

本台账只包含两轮独立核查结论不一致、或有一方未能完成的条目。`pv3 item <id>` 可看到两轮各自的结论与依据（字段 first / second）。

- 不偏向任何一方。逐项亲自核查原文件、原图或计算，给出你的最终结论。
- 一方的证据可复现而另一方不可复现时，采纳可复现的一方；双方证据都成立但解释不同时，回到判定规则（测量值 vs 轴变量、独立实验 vs 同一实验、口径是否一致）作出判断。
- 关键事实确实无法核验时写 unresolved，并在 note 写明缺什么；不要因为无法核验就默认判有风险或无风险。
- basis 必须写明你核查到的具体事实和采纳理由。
